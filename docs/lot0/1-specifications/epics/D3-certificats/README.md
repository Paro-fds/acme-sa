# Epic D3 — Certificats

**Objectif :** L'employé fait valoir ses qualifications en déposant ses certificats et suit leur sort.

**Pourquoi :** Besoin 2 : des qualifications prouvées. Sans certificat validé, personne n'apparaît dans les recherches des RH.
